# Контекст для Claude

Telegram-бот продаж услуги «Составление ТТК» бренда **Техкарты PRO** (@tehkarty_pro_bot).
Владелец работает только с телефона: объяснять по шагам, команды давать в блоках кода.

- Стек: Python 3.11+, aiogram 3.31, SQLite (aiosqlite), FSM в памяти. Запуск: `python main.py`.
- Все тексты, кнопки, цены, FAQ — в `bot/texts.py`. Код хендлеров текстов не содержит.
- Фирменные цвета: зелёный `#1F4D3A`, оранжевый `#E8A33D`, кремовый `#F4F1EA`. Ассеты — `bot/assets/`.
- Деплой: VPS FirstVDS в Амстердаме (сервера в РФ не подходят — провайдеры блокируют api.telegram.org).
  Установка/обновление: `git pull && bash deploy/install.sh` (systemd-служба `ttk-bot`).
- Секреты только в `.env` на сервере, в репозиторий не коммитить (репозиторий публичный).
- Перед пушем: `python -m compileall bot main.py`, `bash -n deploy/install.sh`.
